## 🚀 Features
- **Wide Format Support**: Convert between JPG, PNG, BMP, TIFF, GIF, and **ICO**.
- **Batch Processing**: Convert entire folders of images with one click.
- **Standalone/Portable**: No installation required for the `.exe` versions.
- **Custom ICO Logic**: Specialized byte-level handling for generating valid Windows Icon files.
- **UI Stability**: Optimized layout to ensure consistent button alignment across different displays.

## 📦 How to Download
You can find all versions in the [**Releases**](https://github.com) section. 

**Choose the file that matches your system:**
- **Installer (`.msi`)**: Full setup with Desktop and Start Menu shortcuts.
- **Portable (`x64`)**: Best for most modern PCs (Intel/AMD 64-bit).
- **Portable (`ARM64`)**: For new ARM laptops (e.g., Snapdragon X Elite, Surface Pro).
- **Portable (`x86`)**: For older 32-bit legacy systems.

## 🛠️ How to Use
1. **Select Source**: Choose a single file or an entire folder using the "Browse" buttons.
2. **Select Destination**: Choose where you want to save your new images.
3. **Choose Format**: Click on one of the format buttons (JPG, PNG, TIFF, etc.).
4. **Convert**: Hit the **Convert Now** button and wait for the success notification!
